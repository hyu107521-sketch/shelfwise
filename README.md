# Shelfwise

A small, offline-first pantry tracker. Add food and its best-by date to see what to use next. Shelfwise stores its list in your browser's local storage; nothing is sent to a server.

## Try it

Open `index.html` in a modern browser. No build step or package installation is needed.

## Features

- Add pantry items with category, quantity, and a best-by date
- See at a glance what is past date, due soon, or still fresh
- Search and filter the list
- Keep data in the current browser with local storage
- Load sample items to explore the interface
- Use the responsive layout on desktop and mobile

## Privacy

Your pantry list remains in local storage in the browser where you use Shelfwise. Clearing that browser's site data removes the list. The app does not include analytics, accounts, or a server.
